## 📦 Instalação

### Pré-requisitos
- Node.js v14+
- npm ou yarn
- Git

### Passos

1. Clone o repositório
\`\`\`bash
git clone https://github.com/Tiagoap3524/nome-do-projeto.git
cd nome-do-projeto
\`\`\`

2. Instale as dependências
\`\`\`bash
npm install
\`\`\`

3. Configure as variáveis de ambiente
\`\`\`bash
cp .env.example .env
# Edite o arquivo .env com suas configurações
\`\`\`

4. Inicie o servidor
\`\`\`bash
npm start
\`\`\`

## 💡 Dicas Importantes

### ✅ Faça
- Adicione screenshots e GIFs do projeto funcionando
- Escreva instruções claras de instalação
- Documente todas as APIs e endpoints
- Liste as dependências necessárias
- Inclua exemplos de código
- Mantenha o README atualizado

### ❌ Não Faça
- Deixe o README vazio ou genérico
- Escreva em inglês se for trabalhar com clientes brasileiros
- Omita informações importantes
- Use termos técnicos sem explicar
- Coloque informações desorganizadas

---

## 🎨 Melhorando seu Portfólio

### Para cada projeto, certifique-se de:

1. **README.md** - Documentação completa
2. **Screenshots** - Imagens do projeto em funcionamento
3. **.gitignore** - Arquivos que não devem ser versionados
4. **LICENSE** - Licença do projeto (MIT, Apache, etc)
5. **CONTRIBUTING.md** - Como contribuir (opcional)

### Estrutura recomendada do repositório:

```
meu-projeto/
├── README.md          ← Documentação principal
├── LICENSE            ← Licença do projeto
├── .gitignore         ← Arquivos ignorados
├── package.json       ← Dependências (Node.js)
├── .env.example       ← Exemplo de variáveis
├── src/               ← Código-fonte
├── public/            ← Arquivos estáticos
├── screenshots/       ← Imagens do projeto
└── docs/              ← Documentação adicional
```
